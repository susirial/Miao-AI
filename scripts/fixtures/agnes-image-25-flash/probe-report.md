## Frozen Decisions

- Image input location: **extra_body.image**
- Top-level `response_format` validation: false
- Pixel `size=1024x1024` HTTP: 200; actual: `1024x1024`
- Product sizes: `1K`, `2K`, `3K`, `4K`
- Product ratios: `1:1`, `3:4`, `4:3`, `16:9`, `9:16`, `2:3`, `3:2`, `21:9`

Every HTTP 200 cell matched the official pixel table exactly (`ratioError` 0). Remaining `3K`/`4K` non-square cells returned 429 after retry, not a 4xx validation error. Catalog therefore ships `1K`–`4K` and all eight official ratios. Labels must not treat the request string as the output pixel count.
