# Sketch to Image

Use this dedicated workflow only for `sketch-to-image`. It takes precedence over generic image editing and single-generator questionnaires. Keep every card in the conversation language.

1. **Save the sketch.** Open the inline sketch canvas in the project conversation. The user draws lines and text, then saves the sketch as a PNG project image. Text elements are rendered into that PNG. The saved sketch is image 1 and must remain the first image throughout the workflow. Any other images attached to the same request are explicit initial references. Saving the sketch does not authorize generation. If no saved sketch is attached, ask the user to save one before continuing.
2. **Ask for extra references.** Call `ask_user` alone with exactly one question whose id is `sketch_references`, with `yes` and `no` options. Selecting Yes may upload images or select existing project images; never add project assets automatically. The saved sketch, initial references, and added references combined must not exceed 10 images. Stop and wait for the answer.
3. **Restate and confirm understanding.** Visually inspect the saved sketch and every reference. Describe the intended subject, composition, placement, visible text, style, and the contribution of each reference. Separate observed details from uncertain interpretations and include all prior user corrections. Call `ask_user` alone with exactly one `sketch_understanding` question. Put the concrete restatement in its `prompt`, followed by a request to confirm before generation. Offer `correct` and `adjust`; `adjust` must allow custom text. Stop and wait. A correction requires a revised understanding card. Only an explicit `correct` answer authorizes generation.
4. **Generate immediately after confirmation.** In the next turn, call the preset `generate_image` tool once. Put the saved sketch first, followed by all initial and added references, deduplicated, in `reference_images`; leave `input_urls` empty. Compose a complete generation prompt from the confirmed understanding, numbering the images by their order and preserving requested visible text. The runtime will automatically select Seedream Reference to Image from the populated `reference_images`. Do not choose a provider-specific model tool, request another creative confirmation, show a separate prompt review, or omit the sketch. Existing generation-approval policy may still show its normal execution confirmation.

Reuse completed steps only within the current saved-sketch request. A newly saved sketch starts a new workflow. If the user changes the intent or references before generation, restate the revised understanding and request confirmation again.
